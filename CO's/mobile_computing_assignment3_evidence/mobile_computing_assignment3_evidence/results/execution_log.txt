DSDV-STYLE ROUTE UPDATE WORKED EXAMPLE
Initial route table at A:
Destination D -> next hop B, hop count 2, sequence 16
Event: link A-B fails.
A receives a fresh route advertisement for D via C:
Advertised hop count = 1; sequence number = 18
Decision: accept the fresher sequence number.
Updated route table: D -> next hop C, hop count 2, sequence 18
Note: this is a teaching example of DSDV sequence-number logic, not a full DSDV implementation.

AODV-STYLE ROUTE DISCOVERY
Source S needs a route to D.
S broadcasts RREQ.
S forwards RREQ to A.
A forwards RREQ to B.
B forwards RREQ to D.
D generates RREP.
RREP follows reverse path: B <- A <- S
Installed forward route: S -> A -> B -> D
Data packet forwarded successfully.
Link failure example: A-B goes DOWN.
Affected route is marked INVALID; source may initiate a new RREQ.
Note: this is a simplified AODV-style discovery demonstration, not a complete RFC implementation.
